# استوديو النغم — Nagham Vocal Studio

تطبيق ويب موسيقي متكامل باللغة العربية (RTL) يتيح لك إضافة الموسيقى الخلفية (البيت)، تسجيل صوت الغناء عليها مباشرة من الميكروفون، تعديل فلاتر الصوت الاحترافية، عمل الميكس والماسترينج، واستخراج الأغنية النهائية بصيغة **MP3** أو **WAV** مباشرة داخل المتصفح.

## المميزات

- **مسار الموسيقى الخلفية (Backing Track):** رفع ملفات `MP3` / `WAV` / `M4A` / `OGG` بالسحب والإفلات، مع 3 إيقاعات تجريبية مدمجة (حجاز شرقي، لو-فاي، بوب).
- **تسجيل غناء متزامن (Vocal Recording):** عد تنازلي `3-2-1` مع مترونوم، مقياس إدخال حي، مراقبة حية، تعدد المحاولات (Vocal Takes)، ضبط التزامن (`±250 ms`)، وتخفيض تلقائي ذكي للموسيقى أثناء الغناء (`Auto-Ducking`).
- **فلاتر صوت الغناء (Vocal FX Rack):**
  - 6 قوالب صوت جاهزة (استوديو نظيف، طرب شرقي، راب وهيب هوب، بوب عصري، إذاعي/بودكاست، خام).
  - High-Pass Filter، عزل ضوضاء (Noise Gate)، معادل ترددات 4 نطاقات مع منحنى استجابة ترددية حي، De-Esser، Tube Warmth، ضاغط ديناميكيات (Compressor) مع مؤشر `GR`، تضخيم ستيريو (Doubler)، Convolution Reverb بـ 5 مساحات، و Stereo Delay.
- **الماسترينج (Mastering Suite):** معادل ماستر، توسيع ستيريو Mid/Side، ضاغط دمج (Glue)، ليميتر نهائي (Brickwall Limiter / Maximizer)، محلل طيف ترددي (`FFT`)، ومقياس خرج ستيريو (`VU`).
- **التصدير بصيغة MP3 و WAV:** تصيير عبر `OfflineAudioContext` وترميز حقيقي إلى `MP3` (`128` / `192` / `320 kbps`) عبر `lamejs` محلياً بدون خادم خارجي.

## التشغيل المحلي

```bash
npm install
npm start
```
